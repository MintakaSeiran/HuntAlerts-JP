# HuntAlerts-JP 1.4.1.16

タグ: `1.4.1.7_jp_min.10`。実機未確認のプレビュー版です。

## 変更内容

- 履歴カードの右クリックで、順番待ち中の移動先を別のモブへ切り替えます。
- HuntAlertsが開始した予約を照合し、Lifestream停止とゲーム側予約取消を要求します。
- 取消ログ、予約解除、元ワールド、旧処理とLifestreamの停止を確認してから再申請します。確認中は最後に選択したモブを優先します。
- 旧処理の終了前に新しい処理が開始される競合と、取消後の遅延テレポ/地図操作を防止しました。

## 制限

- 日本語クライアント・同一DC内に対応。「転送予約状態」画面を開き、順番待ち中に操作してください。HUDだけでは切り替えません。
- 転送準備完了後、ロード中、別DC、外部開始・行先不一致の予約は対象外です。
- 取消確認が15秒以内に完了しない場合は再申請せず停止します。
- 他ツールとの同時操作を完全に識別する所有権IPCはありません。同時操作は避けてください。
- ゲーム内操作とインストール済みLifestreamとの互換性は未確認です。
